CAFÉ LUNA — WEB COMPLETA

Archivos:
- index.html     → página principal
- menu.html      → menú
- nosotros.html  → historia y valores
- contacto.html  → ubicación, horario y formulario
- styles.css     → diseño
- script.js      → menú móvil, año automático y formulario de email

CÓMO ABRIR EN GOOGLE CHROME (MAC)
1. Abre la carpeta.
2. Haz clic derecho en index.html.
3. Elige "Abrir con" → Google Chrome.
4. Para navegar, usa el menú de la web.

CÓMO EDITAR
- Textos y precios: abre el archivo .html con un editor de texto.
- Diseño: cambia styles.css.
- Funciones: cambia script.js.

IMPORTANTE
Los datos de contacto y precios son ficticios. Sustitúyelos antes de enseñar esta web como si fuera de un negocio real.

PARA PUBLICAR
Puedes subir los archivos a un servicio de hosting estático. GitHub Pages es una opción para proyectos estáticos y tiene un plan gratuito, pero revisa sus límites y términos antes de usarlo para un negocio real.
